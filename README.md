# TeeHold

Golf coaches take lesson bookings with a **card deposit** so no-shows stop eating the calendar.

Public booking: `/c/:slug` · Coach app: `/app` · SaaS: **$39/mo**

## Quick start

```bash
cp .env.example .env
npm install
npm run db:migrate
npm run dev
```
